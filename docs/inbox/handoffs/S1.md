Paket:

1. **Istraživanje** (`docs/inbox/research/2026-11-XX-resend-primanje.md`, izvor i datum uz svaku tvrdnju; čitaj
   kroz web-fetch agenta, ne iz sjećanja):
   - Resend `POST /emails`: prolaze li `headers: { "In-Reply-To", "References" }` netaknuti? Ako dokumentacija
     ne kaže, zapiši kao otvoreno pitanje za e2e u S2 (ne šalji mail u S1).
   - Svix ručna provjera potpisa: https://docs.svix.com/receiving/verifying-payloads/how-manual (format tajnog
     ključa `whsec_`, što se potpisuje, format `svix-signature` s više potpisa, tolerancija vremena) i službeni
     test vektor ako postoji.
   - Primanje: kako se uključuje za poddomenu `poruke.logomedo.com` verificirane domene `logomedo.com` (ili je
     nova domena), MX vrijednost i prioritet, može li se to kroz API (`/domains`) ili samo u dashboardu.
     Polazni sažetak iz 19. 11.: webhook `email.received` nosi `email_id`, `from`, `to`, `message_id`,
     `subject`, `attachments[]` (`id`, `filename`, `content_type`), bez tijela; tijelo, `headers` i
     `raw.download_url` daje `GET https://api.resend.com/emails/receiving/{id}`; webhook se stvara
     `POST /webhooks` `{ endpoint, events }`, odgovor ima `signing_secret`. Provjeri i dopuni.
   - API za privitke primljenog maila (putanja, potpisani URL ili bajtovi).
2. **Migracija `migrations/0039_inbox.sql`** (provjeri da je 0039 slobodan): `razgovori` (id, kljuc UNIQUE,
   email, ime, korisnik_id NULL, predmet, zadnja_at, neprocitano, status), `poruke` (id, razgovor_id, smjer
   'ulaz'|'izlaz', resend_id UNIQUE, message_id, in_reply_to, od, za, predmet, text, html, created_at,
   procitano_at, poslao), `privitci` (id, poruka_id, r2_kljuc, ime, tip, velicina), `brzi_odgovori` (id,
   kratica UNIQUE, naslov, tekst, updated_at). Indeksi za popis po `zadnja_at` i nepročitano. Odluka o
   granicama (veličina privitka, tipovi).
3. **`src/lib/svix.ts`**: `provjeriPotpis(tajna, zaglavlja, tijelo, sada)` kroz WebCrypto; test sa službenim

4. **`src/lib/poruke.ts`**: `kljucRazgovora()`, `adresaZaOdgovor(kljuc)`, `nadjiRazgovor({ za, inReplyTo,
   od })` (redom iz odluke 4), `spremiDolaznu`, `spremiOdlaznu`, `oznaciProcitano`, `brojNeprocitanih`.
5. **`POST /api/resend/webhook`** (`src/pages/api/resend/webhook.ts`): sirovo tijelo, potpis
   (`RESEND_WEBHOOK_SECRET`, novi opcionalni secret u `src/env.d.ts`), samo `email.received` (ostalo 200 i
