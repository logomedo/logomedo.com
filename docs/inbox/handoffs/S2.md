# S2: primanje na produkciji, Reply-To, privatnost, e2e

Polazni commit: (zadnji commit S1 na `inbox`, vidi „Stanje lanca”). `npm test`: 360 prolazi, `skipped 0`. Odluke od **200**.

Što je S1 ostavio (research `docs/inbox/research/2026-11-19-resend-primanje.md`, odluke 100–111):

- **Primanje na poddomeni:** dokumentacija ne kaže je li `poruke.logomedo.com` zaseban unos u `/domains`. Prvo
  `GET /domains` (vidi ima li `logomedo.com` polje `capabilities`), pa najvjerojatnije `POST /domains`
  `{ name: "poruke.logomedo.com", region: "eu-west-1", capabilities: { sending: "disabled", receiving: "enabled" } }`;
  postojeća domena se mijenja `PATCH /domains/{id}` `{ capabilities: { receiving: "enabled" } }`. Točnu MX
  vrijednost daje odgovor API-ja ili dashboard (primjer u dokumentaciji: `receive-euw1.forge.rmta.net`); prioritet
  mora biti najmanji na toj poddomeni. Zapiši stvarni ishod u research §2 i odluku.
- **Niti:** `In-Reply-To`/`References` u `POST /emails` `headers` su dokumentirani u vodiču za odgovore. Otvoreno:
  koji `Message-ID` dobiva naš odlazni mail (odgovor vraća samo Resendov `id`). U e2e iz `headers` dolaznog
  odgovora (`wrangler d1 … SELECT in_reply_to, reference FROM poruke`) zapiši što Gmail stavi u `In-Reply-To` i
  usporedi s onim što Resend vrati za odlazni mail (`GET /emails/{id}`, ako ima `message_id`/`headers`).
- **Kod je spreman:** `noviRazgovor({ email, ime, predmet })` → `{ id, kljuc }`, `adresaZaOdgovor(kljuc)`,
  `spremiOdlaznu({ razgovorId, resendId, od, za, predmet, text, html, poslao: null })` u `src/lib/poruke.ts`.
  Webhook bez `RESEND_WEBHOOK_SECRET` vraća 503 (odluka 102), pa secret mora biti postavljen prije nego Resend
  počne slati.
- **Staging:** migracija 0039 primijenjena, testni secret postavljen, `scripts/inbox-probni-webhook.ts` zelen
  (u staging D1 su dvije probne poruke `probni_%` u razgovoru `probni@primjer.test`; smiju ostati).

**Vrata:** DNS se mijenja u Cloudflare dashboardu u Braveu (wrangler nema DNS pravo); ako primanje u Resendu nema
API, uključuje se u Resend dashboardu, za koji korisnik mora biti prijavljen. Resend API ključ korisnik stavi u
clipboard. Za e2e korisnik odgovara iz svog pretinca (ili Claude u Braveu, ako korisnik to kaže). Pitaj na
početku sesije i čekaj.
